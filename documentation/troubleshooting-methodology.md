# Windows Troubleshooting Methodology

## Overview

This document outlines a structured approach to diagnosing and resolving common Windows computer problems.

## Troubleshooting Process

### 1. Identify the Problem
Understand the user's complaint and gather information about the symptoms.

### 2. Gather Information
Collect relevant details about the computer, operating system, applications, and recent changes.

### 3. Establish a Probable Cause
Analyze the available evidence and identify possible causes.

### 4. Test Possible Solutions
Perform appropriate diagnostic tests to narrow down the cause.

### 5. Implement a Resolution
Apply the safest and most appropriate corrective action.

### 6. Verify the Resolution
Confirm that the issue has been resolved and the system works as expected.

### 7. Document the Incident
Record the problem, investigation, resolution, and recommendations.

## Important Considerations

- Always obtain user approval before making significant changes.
- Protect user data during troubleshooting.
- Avoid making assumptions without evidence.
- Escalate issues beyond your authorization or technical ability.
- Document all significant actions taken.
