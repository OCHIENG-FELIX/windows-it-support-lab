# Computer Maintenance Checklist

## Purpose

This checklist provides a structured reference for routine Windows computer maintenance to improve reliability, performance, and security.

## 1. Hardware Maintenance

- [ ] Inspect computer casing and physical condition.
- [ ] Check power cables and peripheral connections.
- [ ] Inspect keyboard, mouse, monitor, and other peripherals.
- [ ] Check ventilation areas for dust accumulation.
- [ ] Listen for unusual hardware noises.
- [ ] Check for signs of overheating.

## 2. Operating System Maintenance

- [ ] Check Windows update status.
- [ ] Review Windows security notifications.
- [ ] Confirm antivirus protection is active.
- [ ] Review system error notifications.
- [ ] Check available storage space.

## 3. Software Maintenance

- [ ] Review installed applications.
- [ ] Identify outdated applications.
- [ ] Check startup applications.
- [ ] Remove unnecessary software with authorization.
- [ ] Confirm required applications function correctly.

## 4. Performance Monitoring

- [ ] Review CPU utilization.
- [ ] Review Memory utilization.
- [ ] Review Disk utilization.
- [ ] Identify unusual background processes.
- [ ] Investigate recurring performance problems.

## 5. Data Protection

- [ ] Confirm backup status.
- [ ] Verify that important data is included in backups.
- [ ] Follow organizational data protection policies.
- [ ] Confirm restoration procedures are available.

## 6. Documentation

- [ ] Record maintenance activities.
- [ ] Document identified problems.
- [ ] Record corrective actions.
- [ ] Report unresolved issues for escalation.

## Important Note

Perform maintenance activities according to organizational policies, user permissions, and approved procedures.
