# Scenario 02: High CPU and Memory Usage

## 1. Problem Description

A user reports that their Windows 11 computer becomes slow when running multiple applications. Task Manager indicates unusually high CPU or Memory utilization.

## 2. Symptoms

- Slow system response.
- Applications taking longer to open.
- System freezing or becoming unresponsive.
- High CPU or Memory utilization.
- Increased application loading times.

## 3. Possible Causes

### High CPU Utilization
- Resource-intensive applications.
- Excessive background processes.
- Software running continuously in the background.
- Malware or unwanted processes.

### High Memory Utilization
- Too many applications running simultaneously.
- Browser tabs consuming excessive RAM.
- Memory-intensive applications.
- Insufficient installed RAM.

## 4. Diagnostic Approach

1. Open Task Manager using `Ctrl + Shift + Esc`.
2. Select the Processes tab.
3. Sort processes by CPU utilization.
4. Identify applications consuming the most CPU resources.
5. Repeat the process for Memory utilization.
6. Review startup applications.
7. Observe resource utilization over time.
8. Investigate unfamiliar or suspicious processes before taking action.

## 5. Recommended Resolutions

Depending on the findings:

- Close unnecessary applications after confirming with the user.
- Disable unnecessary startup applications.
- Update applications experiencing performance problems.
- Investigate software using excessive resources.
- Perform an approved security scan when malware is suspected.
- Consider a RAM upgrade if memory limitations are confirmed.

## 6. Verification

- Monitor CPU and Memory utilization after corrective action.
- Reopen the affected applications.
- Confirm improved system responsiveness.
- Ask the user whether the performance issue has been resolved.

## 7. Preventive Recommendations

- Avoid running unnecessary applications simultaneously.
- Monitor resource-intensive applications.
- Maintain updated software.
- Review startup applications periodically.
- Ensure the computer meets the resource requirements of installed applications.
