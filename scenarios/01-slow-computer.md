# Scenario 01: Slow Computer Troubleshooting

## 1. Problem Description

A user reports that their Windows 11 computer takes approximately five minutes to open applications. The computer also becomes slow and occasionally unresponsive when multiple applications are running.

## 2. Symptoms

- Slow application startup.
- Delayed response to user commands.
- System freezing when multiple applications are open.
- Reduced overall computer performance.

## 3. Possible Causes

- High CPU utilization.
- Insufficient available RAM.
- Excessive background processes.
- Too many startup applications.
- Low available storage space.
- Malware or unwanted software.
- Storage device performance issues.

## 4. Diagnostic Approach

1. Open Task Manager using `Ctrl + Shift + Esc`.
2. Review CPU, Memory, and Disk utilization.
3. Identify applications consuming excessive resources.
4. Review startup applications.
5. Check available storage space.
6. Review relevant system errors using Event Viewer.
7. Perform an appropriate security scan if malware is suspected.

## 5. Recommended Resolutions

Depending on the diagnostic findings:

- Close unnecessary applications with user approval.
- Disable unnecessary startup applications after confirming they are not required.
- Remove unnecessary temporary files safely.
- Update applications and Windows where appropriate.
- Investigate excessive resource consumption.
- Consider a RAM or storage upgrade if evidence supports it.

## 6. Verification

After applying the appropriate resolution:

- Restart the computer if required.
- Reopen the affected applications.
- Monitor CPU, Memory, and Disk utilization.
- Confirm that application startup and system responsiveness have improved.
- Ask the user to confirm that the problem is resolved.

## 7. Preventive Recommendations

- Avoid running unnecessary applications simultaneously.
- Maintain adequate free storage space.
- Keep Windows and applications updated.
- Review startup applications periodically.
- Perform regular preventive maintenance.
